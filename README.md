# 词条调研汇报

一个中文词条调研汇报训练工具。抽到一个词条、现象、技术问题或面试问题后，先花时间调研它是什么，再分析它为什么出现、影响是什么，最后完成 1-2 分钟口头汇报。

在线使用：

https://dylanzs1234.github.io/-unprompt.cool-/

## 怎么使用

1. 在右侧选择一个分类，比如日常现象、职场概念、技术问题、社会议题、关系心理、文化消费或面试常用。
2. 选择难度：入门、进阶或挑战。
3. 设置调研、整理、汇报时间。
4. 点击“换词条”，系统会尽量避免重复抽到同一个词条。
5. 按页面给出的“调研什么”“分析什么”去查资料和整理观点。
6. 最后用 1-2 分钟完成口头汇报。

## 功能

- 多分类词条库，包含日常现象、职场概念、技术问题、社会议题、关系心理、文化消费、面试常用。
- 每个词条提供调研方向、分析问题、汇报结构和关键词。
- 面试常用问题提供参考答案，方便先模仿再改写。
- 支持调研计时、整理计时和汇报计时。
- 支持换词条、复制材料、收藏词条、查看历史记录。
- 词汇库放在页面下方，可以展开或折叠。

## 本地运行

需要先安装 Node.js。

```bash
npm install
npm run dev
```

如果 PowerShell 提示脚本被禁止，可以改用：

```bash
npm.cmd install
npm.cmd run dev
```

然后打开终端里显示的本地地址，一般是：

```text
http://127.0.0.1:5173/-unprompt.cool-/
```

## 构建

```bash
npm run build
```

## GitHub Pages

当前仓库名是 `-unprompt.cool-`，所以 `vite.config.js` 里的 `base` 应该是：

```js
base: "/-unprompt.cool-/",
```

部署使用 GitHub Actions，配置文件在：

```text
.github/workflows/deploy.yml
```
